## How to Play / 遊び方 / 如何游玩 / Cómo jugar

Open index.html in a modern browser.  
No local server is required in most cases, but an internet connection is needed because Three.js is loaded from a CDN.

ブラウザで index.html を開いてください。  
多くの場合はローカルサーバーは不要ですが、Three.js を CDN から読み込むためインターネット接続が必要です。

在现代浏览器中打开 index.html。  
大多数情况下不需要本地服务器，但因为游戏从 CDN 加载 Three.js，所以需要网络连接。

Abre index.html en un navegador moderno.  
Normalmente no necesitas un servidor local, pero hace falta conexión a internet porque Three.js se carga desde un CDN.

## Tips / プレイのコツ / 游玩提示 / Consejos

- Clear waves first, then focus on the boss.
- Do not stay near the bottom edge.
- Invincibility frames last only briefly.
- Some enemies shoot multiple bullets.
- Sound OFF can be useful for silent play.

- 敵ウェーブを先に処理してからボスに集中してください。
- 画面の下寄りに留まらないでください。
- 無敵時間は短いです。
- 一部の敵は複数の弾を撃ってきます。
- サウンド OFF で静かにプレイできます。

- 先清理波次，再集中攻击头目。
- 不要长时间停在屏幕下方。
- 无敌时间很短。
- 有些敌人会发射多颗子弹。
- 可以关闭音效进行安静游玩。

- Elimina primero las oleadas y luego céntrate en el jefe.
- No te quedes cerca del borde inferior.
- La invencibilidad dura poco tiempo.
- Algunos enemigos disparan varias balas.
- Puedes jugar con el sonido apagado.
